6. SECURITY IMPLEMENTATION
----------------------------------------------------------------------
Feature                    | Implementation
---------------------------|-----------------------------------------------
Password Hashing           | bcrypt with cost factor 12
PIN Hashing                | SHA-256 with crypto.createHash
SQL Injection Prevention   | Parameterized queries ($1, $2) — zero concat
User Enumeration Prevention| Generic error: "Invalid email or password"
Timing Attack Prevention   | crypto.timingSafeEqual for PIN comparison
Rate Limiting              | Redis-based — IP + user identifier, 60s window
Account Lockout            | 5 failed attempts = 15 minute lock
Audit Logging              | Immutable INSERT-only, never UPDATE/DELETE
Token Security             | RS256 asymmetric, private key sign, public verify
Data Leak Prevention       | Error messages never expose query values or PII
