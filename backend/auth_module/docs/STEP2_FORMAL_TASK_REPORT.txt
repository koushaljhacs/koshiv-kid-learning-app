6. SERVICE DETAILS
----------------------------------------------------------------------

SERVICE 1: otp.service.ts
  Purpose:      OTP generation, storage, and validation
  Storage:      Redis only (zero PostgreSQL)
  TTL:          300 seconds (5 minutes)
  OTP Length:   6 digits
  Hashing:      SHA-256
  Key Format:   otp:<identifier> -> hashed_otp
  Functions:
    - generateOtp(): Returns { rawOtp, hashedOtp } using crypto.randomInt
    - storeOtp(identifier, hashedOtp): Stores in Redis with 5-min TTL
    - validateOtp(identifier, rawOtp): Validates and deletes on success
    - otpExists(identifier): Checks if active OTP exists (anti-spam)

SERVICE 2: jwt.service.ts
  Purpose:      JWT token generation and verification
  Algorithm:    RS256 (asymmetric)
  Key Storage:  keys/private.pem (never committed)
  Access Token: 15 minutes TTL
  Refresh Token: 7 days TTL
  Interface:    TokenPayload { sub, role, email?, handle? }
  Functions:
    - generateTokenPair(payload): Returns { accessToken, refreshToken }
    - generateAccessToken(payload): Access token only (re-auth)
    - verifyAccessToken(token): Decodes and verifies token

SERVICE 3: fido2.service.ts
  Purpose:      WebAuthn/FIDO2 registration for parent biometric auth
  Library:      @simplewebauthn/server
  RP ID:        localhost (dev), auth.koshiv.com (prod)
  Functions:
    - generateFido2RegistrationOptions(userId, userEmail): Options for browser
    - verifyFido2RegistrationResponse(response, challenge): Verify attestation
