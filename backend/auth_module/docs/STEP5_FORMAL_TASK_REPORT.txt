5. WHAT IS SINGLE TRANSACTION (Layman Explanation)
----------------------------------------------------------------------
Like bank transfer: either both debit AND credit happen together,
or neither happens. No money disappears.

In our registration: either ALL 6 INSERTS succeed together,
or ALL are ROLLED BACK. Never partial data.

BEGIN;
  INSERT parent user      -> OK
  INSERT parent profile   -> OK
  INSERT child user       -> OK
  INSERT child profile    -> OK
  INSERT relationship     -> OK
  INSERT consent          -> OK
COMMIT; -- All saved together

If any fails -> ROLLBACK; -- Everything undone
